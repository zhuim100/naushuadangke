# 南农入党培训 · 刷课助手（通用版）

适用于 **Windows 10 / 11 + Microsoft Edge**，换电脑也能用。

自动做四件事：

1. **暂停 → 自动续播**
2. **播完 → 自动回列表，打开下一个「必修 / 未完成」视频**（多集的课按页面真实集数顺序走）
3. **一门课刷完 → 自动回课程中心，进下一门**
4. **弹窗「视频已暂停，点击继续学习」→ 自动点掉**

只处理「必修 / 必读」课件，选修不碰。全部在本机浏览器里点按钮，不接管账号、不上传数据。

---

## 一、第一次安装（约 2 分钟）

1. 把压缩包**解压**到任意位置（例如 `D:\南农刷课助手\`）
2. 双击 **`安装扩展.bat`**
   - 它会把扩展复制到 `%LOCALAPPDATA%\NankaiKaoShi\extension`（固定位置，之后压缩包可以删）
   - 并打开课程中心页面
3. 在 Edge 里依次操作（只需一次）：
   - 地址栏输入 `edge://extensions` 回车
   - 打开左下角「**开发人员模式**」
   - 点「**加载解压缩的扩展**」
   - 选择文件夹：`C:\Users\你的用户名\AppData\Local\NankaiKaoShi\extension`
4. 扩展列表出现「**南农入党培训 · 刷课助手**」即成功

> Edge 重启后若提示「关闭/禁用开发人员模式的扩展」，**一定要选「保留」**。
> 如果被关掉，去 `edge://extensions` 把开关重新打开即可，扩展不会丢。

## 二、每次刷课

1. 双击 **`开始刷课.bat`**
   - 后台启动「看门狗」（负责点防挂机弹窗，不显示窗口）
   - 自动打开课程中心
2. 确认已登录
3. 点网页右下角红色面板的「**开始连续刷课**」

之后不用管。面板会实时显示：`播放中 12:30 / 24:38：xxx`、`打开第 3/11 个：xxx`。

想停：

- 点面板「暂停连续刷课」，或
- 直接关掉那个标签页

## 三、注意事项

- **电脑不要睡眠**：电源设置里「睡眠」设为「从不」。屏幕可以关。
- **别关标签页**：Edge 最小化没事。
- **首次可能被拦自动播放**：面板会提示，在页面上随便点一下即可，之后全自动。
- 播完会**等 5 秒**再跳转，给平台留上报时间。
- 平台会定时弹「视频已暂停，点击按钮后继续学习」——**这是防挂机弹窗，不点会暂停播放**。看门狗每 1.2 秒扫一次，发现就点。
- 网上课程 2 倍速可用（面板可切 1x / 1.25x / 1.5x / 2x），但平台若按实际时长计分，倍速可能不计数，自行取舍。
- 这类培训平台一般禁止脚本代刷，账号异常风险由使用者承担。

## 四、出问题怎么办

| 现象 | 处理 |
|---|---|
| 右下角没有面板 | 确认扩展已启用；刷新页面；确认地址是 `wsdx.njau.edu.cn/cjjy/...` |
| 面板提示「没识别到视频」 | 点面板「调试信息」，把内容发我 |
| 弹窗一直不消失 | 双击 `开始刷课.bat` 会启动看门狗；确认任务管理器里有 `powershell` 在跑；看 `%LOCALAPPDATA%\NankaiKaoShi\logs\watchdog.log` |
| 提示自动播放被拦截 | 在页面上随便点一下 |
| 卡在某个视频 | 面板「调试信息」里有最近日志，也可看 `watchdog.log` |

## 五、卸载

1. `edge://extensions` → 找到扩展 → 「删除」
2. 删除 `%LOCALAPPDATA%\NankaiKaoShi` 文件夹
3. 删除本程序文件夹

> 不写注册表、不开机启动、不留后台服务，删文件夹即彻底干净。

## 六、目录说明

```
南农刷课助手\
  安装扩展.bat        复制扩展 + 打开课程页 + 安装指引
  开始刷课.bat        启动看门狗 + 打开课程中心
  停止看门狗.bat      停掉后台看门狗
  extension\          扩展本体
    manifest.json
    content.js        全部逻辑
    bg.js             后台：用 CDP 发真实点击
  watchdog\
    watchdog.ps1      防挂机弹窗点击器（每 1.2 秒扫一次）
```

日志位置：`%LOCALAPPDATA%\NankaiKaoShi\logs\watchdog.log`

## 七、原理速查

| 判断 | 依据 |
|---|---|
| 哪门课没刷完 | 卡片文字 `必读课件：N` / `已完成必读课件：M`，`N > M` 就进 |
| 进哪一页 | `lesson/video?lesson_id=<id>&required=1&stg=26`（必修标签页） |
| 哪个视频没完成 | 卡片里有没有文字正好是「完成」的小标记 |
| 多集怎么算 | 链接 `v_id` 相同、`r_id` 不同 → 拆成多集按页面顺序播 |
| 播完没有 | `<video>` 的 `ended` 事件 + 5 秒缓冲 |
| 弹窗算不算点掉 | 看门狗用 Windows 无障碍接口点击「继续」，平台认这一种 |
